# Superstore-Sales-Dashboard
 📌 Project Overview

This is a Superstore Sales Analysis project where I analyzed sales data to understand sales performance, profit, orders, product categories, and regional trends.

I used **Microsoft Excel** to clean, analyze, and visualize the data and create an interactive sales dashboard.

 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning and analysis
- **Pivot Tables** – Data summarization
- **Charts** – Data visualization
- **KPIs** – Performance analysis

 🔍 Analysis Covered

- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Profit by Category Analysis
- Segment-wise Sales Analysis
- State-wise Sales Analysis
- Top 10 Products Analysis
- Monthly Sales Analysis
- Overall Sales and Profit Performance

 📊 Dashboard

The Excel dashboard includes:

- **7 KPI Cards**
- **7 Charts**
- **3 Interactive Slicers**

The slicers allow users to filter the dashboard and explore sales data interactively.

 💡 Key Insights

- Analyzed total sales and profit performance.
- Identified sales distribution across different regions.
- Compared sales across product categories.
- Analyzed segment-wise sales performance.
- Identified top 10 performing products.
- Explored monthly sales trends.

 🎯 Project Objective

The main objective of this project is to transform raw sales data into meaningful business insights through an interactive Excel dashboard.

This project helped me gain practical experience in **data cleaning, data analysis, Pivot Tables, KPI analysis, and data visualization**.
